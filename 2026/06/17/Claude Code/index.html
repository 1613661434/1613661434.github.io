1. 概述

Claude Code 是 Anthropic 官方推出的终端 AI 编程助手，直接在你终端里运行，能读/写代码、管理 Git、执行命令、问答交互。

核心理念：你不是在和一个聊天机器人对话，而是在和一个能直接操作你项目的 AI 同事协作。

我的环境

项 值
平台 Windows 11 + Git Bash
模型 DeepSeek v4-pro（通过第三方 API 接入）
使用场景 C++ 项目开发、博客写作、文档整理

3. 核心概念

概念 一句话解释 类比
Skills 可复用的指令集，教 AI 怎么干活 说明书 / SOP

6. 权限模式

Claude Code 提供六种权限模式，控制 AI 操作文件 / 执行命令时需要多少确认。

模式速查表

模式 含义 适合场景 风险
default 标准模式，关键操作需确认 🏠 日常开发 低
acceptEdits 自动接受文件编辑 ✏️ 大量改代码 中低
plan 只读规划，不允许修改 📐 大重构前看方案 低
auto 自动执行大部分操作 ⚡ 想减少打断 中
dontAsk 几乎不询问 🤖 CI / 脚本环境 中高
bypassPermissions 完全跳过权限检查 ⚠️ 容器/沙盒 高

设置方式

方式一：启动参数（临时覆盖）

方式二：/config 命令（永久设置）

在对话中输入 /config，在可视化面板中选择。

方式三：settings.json（手动配置）

优先级：启动参数 > settings.local.json > settings.json

7. 配置文件速查

文件位置一览

文件 路径 作用域

CLAUDE.md ~/.claude/CLAUDE.md 全局（所有项目）
settings.json 项目 .claude/settings.json 当前项目
settings.json ~/.claude/settings.json 全局（用户级）
settings.local.json 项目 .claude/settings.local.json 本地覆盖（不提交 Git）
keybindings.json ~/.claude/keybindings.json 自定义快捷键
credentials.json ~/.claude/credentials.json 凭证信息
memory/ ~/.claude/projects/<项目>/memory/ 持久化记忆存储

8. CLAUDE.md 配置指南

是什么

CLAUDE.md 是给 Claude Code 的项目/个人使用说明书。每次对话开始时，Claude Code 都会自动读取这个文件，把它作为系统指令的一部分。

放哪里

位置 作用范围 典型内容
项目根目录 /CLAUDE.md 仅当前项目 项目架构、技术栈、编码规范
~/.claude/CLAUDE.md 所有项目 个人信息、全局偏好、工具链习惯

怎么写

用 /init 命令可以让 AI 自动分析项目并生成 CLAUDE.md。你也可以手动编写。

9. Skills（技能）

是什么

Skill 是一份专业说明书，教 AI 如何完成特定类型的任务。比如 docx skill 教 AI 怎么操作 Word 文档，pptx skill 教 AI 怎么做 PPT。

存放位置

位置 作用范围
.claude/skills/（项目目录） 当前项目
~/.claude/skills/（用户目录） 所有项目

使用方式

11. Hooks（钩子）

是什么

Hooks 让你在特定事件发生时自动执行操作。比如"每次会话开始时运行某个脚本"、“每次保存文件后格式化代码”。

事件类型

事件 触发时机
SessionStart 会话启动时（对话刚开始）
SessionEnd 会话结束时
UserPromptSubmit 用户提交消息时
PreToolUse 工具调用之前
PostToolUse 工具调用之后
Notification 收到通知时
Stop AI 回答完毕时

12. MCP（模型上下文协议）

是什么

MCP（Model Context Protocol）是一个开放标准，让 AI 模型能安全地访问外部工具和数据源。可以把它理解成 AI 世界的"USB 接口"——只要遵循同一个协议，任何工具都能被任何模型使用。

一个 Plugin 是以上四种能力的打包组合，安装一个插件就一次性获得了相关的技能、智能体、工具和自动化钩子。

14. 上下文管理

核心概念

Claude Code 的"上下文"是指当前对话中被模型"记住"的内容。上下文越大，能记住的越多，但成本也越高、响应越慢。

管理命令

命令 作用 什么时候用
/context 查看当前用了多少 token 想知道还剩多少空间
/compact 压缩上下文（去掉细节保留关键信息） 上下文快满但还没做完
/clear 完全清空，从头开始 话题完全变了

15. 启动参数速查

参数 说明
path 指定工作目录
--model <name> 指定模型，如 --model claude-sonnet-5
--permission-mode <mode> 权限模式（见第6节）
--resume 恢复上次会话
--continue 继续最近的会话
--dangerously-skip-permissions 跳过所有权限检查（⚠️ 危险）
--output-format <fmt> 输出格式：text / json / stream-json
--max-turns <n> 限制最大对话轮数
--verbose 显示详细日志
--version 查看版本
